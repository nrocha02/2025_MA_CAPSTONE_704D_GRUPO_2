## 🔗 Sistema de Navegación

### Niveles de Índices

**Nivel 0 - Raíz:**

```
INDICE.md → Vista general del proyecto
```

**Nivel 1 - Por Vista:**

```
[Vista]/DIAGRAMAS.md → Índice de diagramas de la vista
[Vista]/README.md → Documentación completa de la vista
```

**Nivel 2 - Por Categoría:**

```
[Vista]/[subcarpeta]/README.md → Índice de la categoría
```

**Nivel 3 - Diagramas:**

```
[Vista]/[subcarpeta]/diagrama-*.md → Diagrama individual
```

### Enlaces Bidireccionales

Cada nivel puede navegar hacia arriba y hacia abajo:

```
INDICE.md ↔ DIAGRAMAS.md ↔ [subcarpeta]/README.md ↔ diagrama.md
```

## 📋 Convenciones Establecidas

### Nomenclatura de Carpetas

```
diagramas/              # Vista con una sola categoría
diagramas-[tipo]/       # Vista con múltiples categorías
escenarios/             # Documentos de escenarios
```

### Nomenclatura de Archivos

```
diagrama-[nombre].md            # Diagrama individual
diagramas-[nombre].md           # Múltiples diagramas relacionados
escenario-[nombre].md           # Escenario detallado
README.md                       # Índice de carpeta
DIAGRAMAS.md                    # Índice maestro de vista
RESUMEN-[nombre].md             # Documento resumen
ESTRUCTURA-DIAGRAMAS.md         # Guía de organización
```

### Formato de Enlaces

```markdown
# Desde DIAGRAMAS.md a subcarpeta

[Nombre](./subcarpeta/archivo.md)

# Desde subcarpeta a archivo padre

[← Volver](../DIAGRAMAS.md)

# Cross-referencia entre vistas

[Ver diagrama](../../OtraVista/subcarpeta/diagrama.md)
```

## 🚀 Cómo Usar Esta Estructura

### Para Agregar un Nuevo Diagrama

1. ✅ Identificar la vista y categoría apropiada
2. ✅ Crear el archivo en la subcarpeta correspondiente
3. ✅ Actualizar el `README.md` de la subcarpeta
4. ✅ Actualizar el `DIAGRAMAS.md` de la vista
5. ✅ Verificar que los enlaces funcionen

### Para Buscar un Diagrama

**Opción 1 - Navegación:**

```
INDICE.md → [Vista]/DIAGRAMAS.md → [subcarpeta]/README.md → diagrama
```

**Opción 2 - Búsqueda en terminal:**

```bash
# Por nombre
find . -name "*carrito*" -type f

# Por ubicación
ls "./3-Vista-Proceso/diagramas-flujos/"
```

**Opción 3 - grep:**

```bash
# Por contenido
grep -r "Flujo de Carrito" --include="*.md"
```

### Para Crear Nueva Categoría

1. ✅ Crear subcarpeta con nombre descriptivo
2. ✅ Crear `README.md` en la subcarpeta
3. ✅ Agregar sección en `DIAGRAMAS.md`
4. ✅ Actualizar `ESTRUCTURA-DIAGRAMAS.md`
5. ✅ Mover archivos relevantes

## 🎓 Lecciones Aprendidas

### Mejores Prácticas

1. ✅ **Organizar por tipo/categoría**, no por orden alfabético
2. ✅ **Crear READMEs en cada nivel** para guiar la navegación
3. ✅ **Usar enlaces relativos** para portabilidad
4. ✅ **Convenciones claras de nomenclatura** para consistencia
5. ✅ **Documentar la estructura** para facilitar mantenimiento

### Antipatrones Evitados

1. ❌ Carpetas muy profundas (max 3 niveles)
2. ❌ Demasiadas subcarpetas (11 es razonable)
3. ❌ Nombres ambiguos de carpetas
4. ❌ Falta de documentación de la estructura
5. ❌ Enlaces absolutos en lugar de relativos
